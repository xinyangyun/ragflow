# 账户与登录

## 如何注册新账号？

在注册页面填写邮箱或手机号，设置密码并完成验证码验证后即可创建账号。

## 忘记密码后如何重置？

在登录页点击“忘记密码”，通过绑定邮箱或手机号验证身份后设置新密码。

## 如何修改登录密码？

登录后进入个人中心的安全设置，验证当前密码后可以更新为新密码。

## 为什么收不到验证码？

请检查手机号或邮箱是否填写正确，并查看垃圾邮件；若仍未收到，请等待一分钟后重新发送。

## 如何退出当前账号？

点击页面右上角的头像菜单，选择“退出登录”即可结束当前会话。

# 知识库管理

## 如何创建知识库？

在知识库页面点击“新建知识库”，填写名称并选择默认的解析和检索配置后保存。

## 支持上传哪些文件格式？

常见的 PDF、DOCX、TXT、Markdown、CSV、Excel 和 HTML 文件都可以作为知识库文档。

## 文档上传后为什么不能立即检索？

文档需要经历解析、切分和向量化流程；任务完成并显示成功后才会参与检索。

## 如何删除知识库中的文档？

进入知识库的文档列表，选择目标文档后点击删除；删除后对应分块和向量也会被移除。

## 如何更新已经上传的文档？

删除旧文档后重新上传新版本，或者在支持更新的场景中重新触发解析任务。

# 检索与问答

## 什么是向量检索？

向量检索会把问题和文档转换为数值向量，再根据语义相似度找到最相关的内容。

## 如何提高检索准确率？

可以优化文档质量、调整分块大小和重叠比例、选择合适的向量模型，并增加重排序步骤。

## 为什么检索结果与问题不相关？

可能是文档内容不足、分块不合理、查询表达过于模糊，或使用的向量模型不适合当前语料。

## Top-K 参数有什么作用？

Top-K 决定检索阶段返回多少条候选内容；数值越大召回越广，但可能引入更多无关上下文。

## 重排序模型有什么作用？

重排序模型会对初步召回的候选内容再次评分，将与问题最相关的内容排到前面。

# 系统与数据

## Chroma 数据库存储在哪里？

独立 demo 默认将 Chroma 数据保存在脚本同级的 chroma 数据目录，也可以通过命令行参数指定新路径。

## 如何备份向量数据库？

停止写入任务后，备份 Chroma 持久化目录中的全部文件即可；恢复时使用相同目录重新启动程序。

## 如何清空测试数据？

删除测试使用的 Chroma 持久化目录，或为测试指定新的 collection 名称和数据库路径。

## API Key 应该如何保存？

建议通过环境变量提供 API Key，不要把密钥直接写入脚本、Markdown 文件或提交到代码仓库。

## 如何查看问答解析结果？

运行 qa_demo.py 并添加 --pairs-only 参数，程序会打印每个识别出的问答对而不会调用向量接口。
